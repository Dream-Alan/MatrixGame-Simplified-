# 线性代数小游戏（C++ 精简版）

把原 Python（tkinter）版的线性代数矩阵小游戏重写为 C++ + 原生 Win32 实现，
**全部代码 998 行**，零第三方依赖，为课程设计上台讲解而拆分模块。

> 完整的代码讲解、模块说明、分工建议、答辩问答见 **[代码结构说明.md](代码结构说明.md)**。

## 快速开始

```
build.bat           :: 编译，得到 LinearAlgebraLite.exe
build.bat test      :: 编译并运行核心逻辑测试（49 项断言）
```

双击 `LinearAlgebraLite.exe` 即可开玩，进度自动存到同目录的 `progress.txt`。

需要 Windows + 支持 C++17 的 MinGW-w64 g++。
编译器默认在 `C:\Program Files\CodeBlocks\MinGW\bin`，换位置时改 `build.bat` 里的 `MINGW_BIN`。

## 玩法

用**初等行变换**把矩阵变成目标形状，三种模式：

| 模式 | 起始 | 目标 |
|---|---|---|
| 化简 | 随机可逆矩阵 | 化成单位矩阵 |
| 复原 | 单位矩阵 | 变回给定的目标矩阵 |
| 求逆 | 随机可逆矩阵（右边为单位阵） | 左边化单位阵，右边即为逆矩阵 |

## 按键

| 按键 | 作用 |
|---|---|
| `Ctrl` + `1`~`9` / `0` | 选中第 1~10 行（也能用鼠标点格子） |
| `w` / `s` | 当前行上移 / 下移 |
| `r` | 与上一次选的行交换 |
| `q` / `e` | 当前行减去 / 加上上一次行 |
| `f` | 当前行取负 |
| `a` / `d` | 当前行除以 / 乘以 k（连按则 k 递增：2→3→4…） |
| `z` / `x` | 撤销 / 重做 |

## 代码结构（998 行）

| 模块 | 文件 | 行数 | 职责 |
|---|---|---:|---|
| 1 | `fraction.h` / `fraction.cpp` | 96 | 精确有理数，杜绝浮点误差 |
| 2 | `matrix.h` / `matrix.cpp` | 102 | 矩阵、求秩、三种初等行变换 |
| 3 | `game.h` / `game.cpp` | 211 | 三种模式统一成一个状态机 |
| 4 | `ui.h` / `ui.cpp` | 264 | Win32 控件封装、消息循环、DPI |
| 5 | `main.cpp` | 235 | 启动器、界面组装、进度存档 |
| — | `tests/test_core.cpp` | 90 | 49 项断言，验证下面三层 |

依赖是**单向**的：`main → ui / game → matrix → fraction`，
所以 `fraction` / `matrix` / `game` 三层完全不认识 Win32，可以在命令行里单独测试。
